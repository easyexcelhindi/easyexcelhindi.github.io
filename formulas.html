Excel Formula Cheat Sheet

Copy these common formulas into your practice workbook.

SUM

=SUM(B2:B10)

Add values in a range.

AVERAGE

=AVERAGE(B2:B10)

Calculate the average.

IF

=IF(B2>=50,"Pass","Fail")

Return one result when a condition is true and another when false.

COUNTIF

=COUNTIF(B2:B10,">50")

Count cells matching a condition.

SUMIF

=SUMIF(A2:A10,"North",B2:B10)

Add values matching a condition.

VLOOKUP

=VLOOKUP(E2,A2:C10,3,FALSE)

Look up a value in a table.

XLOOKUP

=XLOOKUP(E2,A2:A10,C2:C10,"Not found")

Flexible modern lookup.

IFERROR

=IFERROR(A2/B2,0)

Replace errors with a chosen result.

FILTER

=FILTER(A2:C10,B2:B10>100)

Return rows meeting criteria.

UNIQUE

=UNIQUE(A2:A100)

Return unique values.
