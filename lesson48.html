Lesson 48: Power Query Basics

Import and clean data with Power Query.

What you will learn

  • Understand the key idea behind Power Query Basics.
  • Follow a practical Excel example.
  • Practice the skill using your own worksheet.

Step-by-step

  1. Open Microsoft Excel and create a new workbook.
  2. Enter a small sample dataset in cells A1:C6.
  3. Apply the technique explained in this lesson.
  4. Check the result and change the sample values to test it.

Practice example

Try this formula or technique:

=UNIQUE(A2:A10)

Practice task

Create a small table with at least 5 records. Apply today's skill, change two values, and verify that the result updates correctly.
